# ColorCraft

Updated version with a much stronger color search engine.

## Search improvements
- Exact basic color matches: red, blue, green, yellow, orange, purple, pink, brown, black, white, gray, navy, teal, cyan, gold, etc.
- Many extended names: coral, salmon, burgundy, emerald, sage, mint, cobalt, lavender, terracotta, coffee, ivory, charcoal, and more.
- Handles common aliases and spelling variants.
- Hex input such as #FF0000 is recognized.
- Searches phrases such as "dark blue", "pastel", "luxury", "ocean", "sunset", "nature", "professional", "gaming", etc.
- Exact named palette matches are checked before fuzzy matches.
- Exact searched colors are guaranteed to appear in the generated result.
- 2, 3 and 4 color gallery contains hundreds of combinations.

## AdSense
Advertisement placeholders remain in the HTML. Replace them with the AdSense code supplied by Google after approval and follow current AdSense policies.

## Run
Open index.html in a browser.
